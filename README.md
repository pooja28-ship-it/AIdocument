# AI Document Intelligence Platform

An AI-powered document intelligence platform built with:

- FastAPI
- PostgreSQL
- Next.js
- OpenAI
- JWT Authentication
- PDF text extraction
- AI document summarization

## Features

- User registration and login
- Secure JWT authentication
- PDF document upload
- PDF text extraction
- Document summaries
- Document management
- AI-powered document analysis
